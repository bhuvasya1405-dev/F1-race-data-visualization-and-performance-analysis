
F1 Multi Analyzer is a Flask-based web application that analyzes Formula 1 race data using FastF1. It provides multi-driver comparison, lap time analysis, fastest lap insights, and full telemetry visualization through an interactive dashboard.

---
User authentication (login/register system)
 Lap time comparison across drivers
 Fastest lap speed analysis
 Full telemetry visualization (Speed, Throttle, Brake, RPM, Gear)
 Circuit map with speed-based coloring
 Graphical insights using Matplotlib
 Multi-driver analysis support

---

 Technologies Used
- Python  
- Flask (Web Framework)  
- FastF1 (F1 Data API)  
- Pandas, NumPy  
- Matplotlib  
- SQLite (Database)
